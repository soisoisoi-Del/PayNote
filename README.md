# PayNote

大学生向けのおこづかい帳 PWA。次の入金日まで、1日あといくら使えるかを表示します。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例: `paynote`、Public）
2. このフォルダの中身（index.html, manifest.webmanifest, sw.js, icon-*.png）をリポジトリ直下にアップロード
3. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後、`https://<ユーザー名>.github.io/paynote/` で開けるようになる

## iPhone のホーム画面に追加

（アップデートのときは、追加し直す必要はありません。追加し直すと記録が消えます）

1. Safari で上の URL を開く
2. 共有ボタン → 「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、アプリのように全画面で動き、オフラインでも使える

## データについて

- 記録は、開いた場所ごとに別々に保存されます（パソコンのEdge、iPhoneのSafari、ホーム画面のPayNoteはそれぞれ別で、同期しません）
- iPhoneでは、ホーム画面のアイコンを削除すると、そのPayNoteの記録も一緒に消えます
- 消える前に、設定 → バックアップ →「ファイルに保存」か「テキストでコピー」で保存しておけば、「ファイルから読み込む」「テキストを貼り付けて読み込む」で戻せます。別の端末に記録を移すときも同じ方法です
- 読み込みは追加する形なので、すでにある記録が重複したり消えたりすることはありません
- 記録はどこにも送信されません
- アプリを更新したときは sw.js の `CACHE` の名前（paynote-v15 → paynote-v16 など）を変えると、新しい版が反映されます
